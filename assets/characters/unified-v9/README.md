# 三职业可换装完整姿势 v9

由内置 imagegen 生成。原始提示词、源图、透明背景修复图保留在此目录，PNG 已嵌入来源。scripts/pack-unified-v9.py 只做分格、等比例缩放、alpha噪点门限与挂点记录。

idle4、hurt4、walk8、run8、jump8、战士三段攻击各8、射手攻击8、法师攻击8，共72完整身体帧。每帧256×256，脚根128/224；角色体高约146源像素，实际战斗缩放.64。

完整姿势决定头、躯干、四肢关系；装备沿 hand/head/hip 挂点呈现，服装共享青蓝染色区。衣服包括金属肩护/绿色短衣/紫色裙摆，武器与头盔使用项目已有不同样式部件。品质>=精良的边饰及高品质握柄细节不同。equipment-visuals.js 是外观注册表；未来新物品增加注册项并提供图像/颜色/锚点，无需复制全部动作，也不退回旧IK模型。

发型和发色为共享头部的染色/后层长发附件。法术和箭矢的发射点取自同一完整姿势挂点，左右镜像一致。战士技能复用三种斩击身体帧并配合已有技能光效，当前demo不包含为每个技能单独绘制的完整新动作组。
