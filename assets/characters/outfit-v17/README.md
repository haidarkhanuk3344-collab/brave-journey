# 装备画风与动作 v17

衣服使用与 cartoon-v15 人物相近的暖色描边、简化色块和阴影。源图由内置 imagegen 生成，参考人物原始整帧与 v16 衣服结构；生成提示词保存在 prompts.json。

## 文件

- source.png：原始透明装备素材页，保留原图。
- armor/tunic/robe-chest.png：胸部材质。
- armor/tunic/robe-hem.png：铠甲腰片、皮衣衣尾与长袍衣摆，移除源图上重复的腰带。
- armor/tunic/robe-icon.png：背包、掉落与商城使用同一套衣服源图。
- tracks.json：五个人物造型每一帧的躯干轮廓和腰缝位置。

## 动作接入

原始人物的完整动作保持不变。胸部纹理根据每个姿势的肩部与腰部位置贴合，上衣轮廓、围巾、皮肤、勋章和腰带保留。衣摆的腰部固定，下缘单独变形，并依据速度、步态、跳跃、挥剑与落地产生短促惯性；铠甲、皮革、布料的柔软程度分别处理。手臂保持原始逐帧前景，收腿跳跃时前腿盖住衣摆。

生成方式：内置 imagegen；无外部 API 回退。
重建裁切与轮廓数据：python3 scripts/pack-outfits-v17.py。
