# 林地怪物 v14

本套由内置 imagegen 根据用户两张参考的风格生成，并已接入游戏。

- `source-atlas.png`：保留的透明生成源图，七种敌人各有站立、移动、蓄力、攻击四个绘制关键姿态。
- `prompt.txt`：完整生成提示词。
- `manifest.json`：图集尺寸、脚底锚点、实际体型与各帧边界。
- 七张同名 PNG：切分后的运行图集。左右方向共用原图并翻转，受击、死亡和移动呼吸由共用渲染处理。
- `../../../scripts/pack-enemies-v14.py`：打包方式，去除相邻格子的碎片，保留原图和透明通道；同怪物所有帧共享缩放，脚底保持同一锚点。

怪物：苔芽团、灰棘狼、蘑菇斥候、猛獠野猪、岩骨统领、荆棘守卫、腐果古树。

## 机制

- 猛獠野猪：锁定方向后冲锋，也会近身践踏；冲锋后有失衡窗口，可跳过冲锋或走出冲刺路径。
- 岩骨统领：正面举盾减伤，绕背可正常攻击；技能可削减盾的耐久，破盾后出现较长反击窗口。重砸与双重地面震波可用跳跃躲避。
- 荆棘守卫：提前标记三处地面并释放缠根，命中造成短暂减速；技能可以中断尚未释放的根刺。施法与收招时可抓住弱点攻击。
- 腐果古树：重砸与震波、连续根刺、落下的腐果爆弹。生命降到一半时只切换一次阶段，并增加反向震波、五处根刺、三颗腐果；每次攻击都有预警与收招窗口。

不改变玩家的动作、装备成长、存档结构或四图永久解锁规则。旧存档可继续使用。验证截图和测试结果位于 `../../../verification/enemies-v14/`。
