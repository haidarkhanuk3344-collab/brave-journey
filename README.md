# 勇者旅途 / Brave Journey

一款正在开发中的单机 2D 横版冒险游戏原型，使用 HTML、CSS、JavaScript 和 Canvas。采用手绘卡通风格，包含战士、射手、魔法师三个职业。

## 当前内容

- 城镇、四张推进式关卡、精英怪与区域 Boss。
- 装备、强化、重铸、商城、技能点与赏金任务。
- 新建角色、读档和删除存档。存档保存在当前浏览器本地，不会上传到 GitHub，也不包含在仓库中。
- 角色外观、装备预览和战斗反馈仍在迭代。

当前主入口保留可玩版本。`design-previews/hero-motion-v33/all-actions.html` 是三职业完整动作第一批预览，包含 136 帧样段；它尚未替换正式角色，也尚未完成所有性别、发型和装备适配。

AI NPC、动态任务等仍处于讨论阶段，本版本尚未实现运行时 AI 功能。部分视觉素材由 AI 辅助生成。

## 本地运行

需要 Python 3，无须构建前端：

```sh
python3 -m http.server 8879 --bind 127.0.0.1
```

在仓库目录执行后，访问 <http://127.0.0.1:8879/>。如果端口被占用，可改为 8880。请通过 HTTP 服务打开，直接双击 HTML 可能无法加载素材。

动作预览：<http://127.0.0.1:8879/design-previews/hero-motion-v33/all-actions.html>。

## 操作

- A / D：移动，连续按两次同方向键进入冲刺。
- J：普通攻击。
- K：跳跃、二段跳。
- Q / W / E：技能。

其他功能以游戏内界面为准。

## 测试

需要 Node.js 18 或更新版本：

```sh
npm test
```

仓库附带可独立运行的逻辑测试。素材的视觉质量还需要在实际游戏及预览页中检查，测试通过不等于全部美术适配完成。

## 目录

- `index.html`：游戏入口。
- `game.js`、`rules.js` 等：游戏逻辑与渲染。
- `assets/`：运行与动作验证素材。
- `design-previews/`：设计样张和逐帧动作预览。
- `vendor/`：第三方代码及原许可证。
- `tests/`：逻辑测试。
